You can also create a powerup from an existing repo's code instead of starting
starting from scratch:

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: `pup create saas-starter \\ 
\t--capture=all \\ 
\t--description="Scaffolds a SaaS starter" \\
\t--intent="Saas, Nextjs with tailwind and auth0" \\
\t--variables=theme,projectName,auth0ClientId,auth0Domain,auth0Audience \\
\t--type=single-use
`, language: 'bash' },
]} />

| Flag | Option | Description |
| --- | --- | --- |
| capture | `all` | Turns all files into powerup templates. |
| capture |`workingDir` | Turns only the current uncommitted git changes into powerup templates. |
