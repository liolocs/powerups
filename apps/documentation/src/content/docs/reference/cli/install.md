Install a powerup locally or globally

```sh
pup install [flags]
```

## Flags

| Flag | Short | Type | Description |
| ---- | ----- | ---- | ----------- |
| `--dry-run` | `-dr` | boolean | Print output to stdout instead of writing files |
| `--local` | `-l` | boolean | Install to local project store instead of global |
