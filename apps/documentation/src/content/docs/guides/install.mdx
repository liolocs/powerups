The `pup` cli tool helps you manage your **powerups**.
It is intended to be used by your favorite AI harness.

## Install

<CodeBlock autoHeight files={[
  { filename: 'pnpm', code: 'pnpm add -g @liolocs/powerups-cli', language: 'bash' },
  { filename: 'npm', code: 'npm install -g @liolocs/powerups-cli', language: 'bash' },
  { filename: 'yarn', code: 'yarn global add @liolocs/powerups-cli', language: 'bash' },
  { filename: 'bun', code: 'bun add -g @liolocs/powerups-cli', language: 'bash' }
]} />

Requires [Node.js](https://nodejs.org/).

## Verify

<CodeBlock autoHeight files={[
  { filename: 'bash', code: 'pup --version', language: 'bash' },
]} />
