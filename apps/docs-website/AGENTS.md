## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Generated content

The pages under `src/content/docs/` are generated by
`scripts/generate-docs.ts` (wired into `pnpm dev` and `pnpm build`) — don't
hand-edit them. Sources: the built CLI command registry
(`packages/cli/lib/commands/index.js`), `packages/sdk/README.md`, and the njk
templates in `scripts/templates/`. The generator needs a packages build first
(`pnpm --filter @liolocs/powerups-cli build`); it exits with that instruction
when the registry is missing.
