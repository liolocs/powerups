Install the powerup CLI's built-in skills into a harness's global skills
directory. Existing files are left untouched — use `pup harness update` to
overwrite them.

<CodeBlock autoHeight files={[
  {
    filename: 'bash',
    language: 'bash',
    code: `pup harness init <harness>`
  }
]} />

`<harness>` is one of the harnesses the CLI supports. Skills are written
relative to your home directory:

| Harness | Skills directory |
| ------- | ---------------- |
| `claude` | `~/.claude/skills` |
| `opencode` | `~/.opencode/skills` |
| `pi` | `~/.pi/agent/skills` |
| `codex` | `~/.codex/skills` |

## Flags

| Flag | Short | Type | Description |
| ---- | ----- | ---- | ----------- |
| `--dry-run` | `-dr` | boolean | Print output to stdout instead of writing files |
