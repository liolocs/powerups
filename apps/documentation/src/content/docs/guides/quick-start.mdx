## Install a powerup 

Powerups can be installed from either npm or git repos:

<CodeBlock autoHeight files={[
  { filename: 'npm', code: 'pup install npm:@liolocs/powerup-hello-world', language: 'bash' },
  { filename: 'git', code: 'pup install git@github.com:liolocs/powerup-hello-world.git', language: 'bash' },
]} />

This will save the powerup in the global `~/.powerups` folder 

Refer to the [install](/docs/reference/cli/install/) api for more info.

## Use a powerup

Using a powerup will apply its coding instructions in your current working directory.

1. Use the powerup-hello-world:

<CodeBlock autoHeight files={[
  { filename: 'bash', code: 'pup use powerup-hello-world --target-dir=./hello-world-test', language: 'bash' },
]} />

2. Resulting in the following output:

<CodeBlock autoHeight files={[
  { filename: 'bash', code: `Created: index.ts
Created: package.json

✓ Powerup powerup-hello-world was successfully used in /Users/<user>/<path>/hello-world-test`, language: 'bash' },
]} />

- Refer to the [powerup-hello-world](/powerups/@liolocs/powerup-hello-world) page for more details on the powerup.
- Refer to the [use](/docs/reference/cli/use/) api for more info on the use command 

## Remove a powerup

You can remove the powerup by using just the powerup name:

<CodeBlock autoHeight files={[
  { filename: 'npm', code: 'pup uninstall powerup-hello-world', language: 'bash' },
  { filename: 'git', code: 'pup uninstall git:@github.com/liolocs/powerup-hello-world', language: 'bash' },
]} />

or by using the full package source:

<CodeBlock autoHeight files={[
  { filename: 'npm', code: 'pup uninstall npm:@liolocs/powerup-hello-world', language: 'bash' },
  { filename: 'git', code: 'pup uninstall git:@github.com/liolocs/powerup-hello-world', language: 'bash' },
]} />

Like `install`, it removes from the global store unless you pass `--local` or `-l`.
