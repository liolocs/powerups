## 1. Create the powerup

The first step is to create the powerup package. This is done using the `pup create` command.

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: `pup create hello-world \\ \n\t--description="Creates a hello world script" \\
  \t--variables=name \\
  \t--type=single-use 
`, language: 'bash' },
]} />


This creates `~/.powerups/installed/_internal/hello-world/` with the following structure:
<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'templates/hello-world.ts', code: `├── index.ts # the instructions file
├── package.json
├── tsconfig.json
├── .gitignore
└── scripts
    └── create-github-repo.sh
`, language: 'markdown' },
]} />

### A. Setup the package.json

By default the instructions file is mapped to `index.ts`, this is done in the `package.json`'s powerup/instructions property.


<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'package.json', code: `{
\t"name": "hello-world",
\t// ...
\t"powerup": {
\t\t"instructions": "index.ts" // <-- Here
\t}
}
`, language: 'jsonc' },
]} />


### B. Modify the instructions file

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'index.ts', code: `import { defineInstructions, type Instructions } from "@liolocs/powerups-sdk";

const instructions: Instructions = {
  name: "hello-world",
  type: "single-use",
  description: "Creates a hello world script",
  variables: {
    required: ["name"],
    optional: [],
  },
  intent: [
    "create a hello world script",
  ],
  steps: [
    {
      type: "create",
      name: "hello-world.ts",
      template: "templates/hello-world.ts",
      outputPath: "hello-world.ts",
    },
  ],
};

export default defineInstructions(instructions, import.meta.url); // <-- Required`, language: 'ts' },
]} />

The defined steps in the file are executed when running `pup use`.

E.G. Running the command 
<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: 'pup use hello-world --name="world"', language: 'bash' },
]} />
This will create a file called `hello-world.ts` in the root of the folder it is run from.

### C. Create the template

The template is the file that will be used to create the instructions file. It is a file that is rendered by the cli.

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'templates/hello-world.ts', code: `export default function(variables: Record<string, string>): string {
\tconst { name } = variables;
\treturn \`console.log("Hello \${name}!");\`;
}
`, language: 'ts' },
]} />

## 2. Build the powerup

You must build the powerup before it can be used with the command:

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: 'pup build', language: 'bash' },
]} />

This will run a verification on the instructions file and create a `dist` folder containing the necessary files for the powerup to be used. 

## 3. Use powerup

Once the powerup is built you can use it by running the following command:

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: 'pup use hello-world --name=world', language: 'bash' },
]} />

## 4. Share the powerup

Once the powerup is built you can share by publishing it to npm or git.

### Publishing to npm

To publish the powerup to npm run:

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: 'npm publish', language: 'bash' },
]} />

You may use the conventional commits preset to generate the changelog.

Users will then be able to install the powerup by running:

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: 'pup install npm:hello-world', language: 'bash' },
]} />

### Publishing to git

To publish the powerup to git simply push the package to a git repo.

You may run the following script to create a github repo using the gh cli and push the package to it.

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: './scripts/create-github-repo.sh', language: 'bash' },
]} />

Users will then be able to install the powerup by running:

<CodeBlockWithMultiplePackageManagers client:load autoHeight files={[
  { filename: 'bash', code: 'pup install git:github.com/<owner>/hello-world', language: 'bash' },
]} />
