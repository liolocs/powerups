Uninstall a powerup

```sh
pup uninstall [flags]
```

## Flags

| Flag | Short | Type | Description |
| ---- | ----- | ---- | ----------- |
| `--dry-run` | `-dr` | boolean | Print what would be removed without making changes |
| `--local` | `-l` | boolean | Uninstall from local project store instead of global |
