Convert a static step to a dynamic step. Run from the powerup's root directory — the `<outputPath>` argument is the step's output path.

<CodeBlock autoHeight files={[
  {
    filename: 'bash',
    language: 'bash',
    code: `pup author template <outputPath> [flags]`
  }
]} />

Finds the `create` or `modify` step (static or dynamic)
with that output path and converts it

## Flags

| Flag | Short | Type | Description |
| ---- | ----- | ---- | ----------- |
| `--revert` | `-r` | boolean | Convert a dynamic (template) step back to static |
| `--engine` | `-e` | string | Template engine for conversion: `ts` (default) or `njk` |
